# Project-Railway-Bus-Ticket-Booking-System-
T🚆 Railway/Bus Ticket Booking System

A web-based Railway/Bus Ticket Booking System developed using Django Framework that allows users to search vehicles, book tickets, manage passengers, and generate digital tickets with QR verification.

This system simulates real-world ticket reservation platforms like IRCTC and RedBus.

📌 Features
👤 User Module

User Registration & Login

Profile Management

Dashboard with booking statistics

Booking History

🔍 Booking Module

Search vehicles by source & destination

View available schedules

Coach selection system

Seat availability tracking

Multiple passenger booking (max 5)

🎟 Ticket Module

Automatic PNR Generation

Ticket generation after payment

QR Code ticket verification

Printable ticket layout

💳 Payment Module

Dummy payment integration

Payment record storage

Booking confirmation after payment

🔔 Notification Module

Booking confirmation alerts

Cancellation notifications

System messages

❌ Cancellation

Ticket cancellation feature

Booking status update
